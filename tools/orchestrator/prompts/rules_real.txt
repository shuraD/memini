Database and libraries (every agent, every ticket; the second rule is checked by the library-warning gate):
- code that calls the database or an installed library is proven by at least one test that runs against the real database or the real library; a fake may stand in only for another task's code that is not built yet, never for the database or a library
- never call a function, class or procedure whose own documentation marks it as not for production, experimental, alpha or deprecated; use the supported call (the gate reads the docstrings of the installed libraries for: $phrases)
